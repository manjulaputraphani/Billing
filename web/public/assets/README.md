# Static assets

Drop the login photo here as **`login-bg.webp`** (the web app loads
`/assets/login-bg.webp` for the left-hand panel of the sign-in page).

- Recommended: 1200×1600 px (portrait), WebP, under ~300 KB
- The panel has a solid brown fallback, so the page still looks right while
  the image loads (or if it is missing)
